과제 05 · 공개 피부 병변 이미지 · 프라이버시 보호 학습

프라이버시를 보호하면, 표본이 적은 피부 병변은 더 쉽게 놓칠까요?

공개 피부 병변 이미지로 클라이언트 6개의 연합학습을 모의 실험해, 프라이버시 보호가 소수 클래스* 인식에 주는 영향을 연구하고 이를 줄이는 방법을 비교합니다.

바로 답하면지금까지의 관찰로는 그렇습니다. 프라이버시 보호를 넣으면 피부섬유종과 혈관 병변이 흔한 멜라닌세포 모반보다 크게 떨어지고, 시험한 완화 방법은 아직 안정적으로 개선하지 못했습니다. 결과는 검토 대기입니다.

* 소수 클래스: 현재 학습 분할에서 표본 비율이 낮은 클래스. 이 연구는 피부섬유종(DF)과 혈관 병변(VASC)을 보며, 임상적 희귀 질환과 같지 않습니다.

기술 세부: 과제, 지표, 프라이버시 단위
  • 과제: Fed-ISIC2019의 8개 클래스 피부 병변 분류.
  • 지표: 클래스별 재현율, 균형 정확도(8개 클래스 재현율의 평균), Macro-F1(8개 클래스 F1의 평균).
  • 프라이버시: 이미지/표본 단위 차등 프라이버시(DP-SGD 학습, RDP 회계), 모델마다 목표 상한 ε≤3. 이미지 단위 보호가 곧 환자 단위 보호는 아닙니다.
  • 적용 범위: 공개 데이터의 연합학습 모의 실험, 출처 구획 6개.

03

공개 데이터로 왜 연합학습을 하나요?

바로 답하면누구나 구해서 재현할 수 있는 공개 데이터로, 데이터가 여러 참여자에게 흩어진 조건을 모의하고, 협력 학습과 프라이버시 보호 방법을 비교합니다.

공개 데이터재료의 출처

공개 데이터셋 이미지라 누구나 내려받아 확인할 수 있습니다. 병원 진료 기록은 쓰지 않았습니다.

연합학습구획별 협력

이미지는 각 구획에 두고 로컬에서 학습한 뒤 모델 파라미터만 서버에 보내 합칩니다. 이것이 연합학습(FL)입니다.

차등 프라이버시기록 한 건의 영향 제한

이미지 한 장의 영향을 제한하고 노이즈를 더해, 그 이미지가 들어 있었는지 알 수 없게 합니다. 이것이 차등 프라이버시(DP)이며 예산 ε가 작을수록 보호가 강합니다.

  1. 서버가 현재 모델을 클라이언트 6개에 보냅니다 보내는 것은 모델 파라미터이며 이미지는 없습니다.
  2. 각 클라이언트가 로컬에서 학습: DP-SGD 샘플별 그래디언트 클리핑 + 노이즈 학습의 매 단계에서 이미지 한 장의 그래디언트 기여를 제한한 뒤 가우스 노이즈를 더합니다. 이미지는 계속 로컬에 있습니다.
  3. 보호된 모델 업데이트만 올립니다 DP-SGD로 학습한 모델 파라미터를 올리며 이미지는 올리지 않습니다. P2는 1단계 학습이 끝난 뒤 노이즈를 더한 클래스 통계를 한 번 더 올립니다.
  4. 서버가 가중 평균해 다음 라운드 모델을 만듭니다 클라이언트별 표본 수로 가중 평균(FedAvg)해 다시 보내고 여러 라운드 반복합니다. P2는 마지막에 노이즈 통계로 균형 가상 특징을 만들어 분류기를 다시 학습합니다. 효과는 시험 세트로 평가합니다.

소수 클래스는 왜 더 손해를 볼 수 있을까요?

개념 설명용 강도 (실제 ε나 정확도 값이 아님)

같은 간섭에서도 수가 적은 마름모가 더 알아보기 어렵습니다.

슬라이더는 그림의 가림만 바꾸며, DP를 실행하지 않고 실제 ε나 정확도와 대응하지 않습니다.

기술 세부: 프라이버시 설정
  • 연합 평균(FedAvg): 서버가 클라이언트별 표본 수로 모델 파라미터를 가중 평균합니다.
  • DP-SGD: 매 단계 이미지마다 그래디언트를 고정 노름으로 자른 뒤 가우스 노이즈를 더하고, RDP 회계로 (ε, δ)를 계산합니다. δ는 고정합니다.
  • 보호 단위: ISIC 실험은 이미지/표본 단위, 흉부 영상 확장 실험은 환자 단위입니다.
  • 예산: 모델마다 목표 상한 ε≤3이며 P2의 클래스 통계 공개도 예산에 포함합니다. 방법마다 실제 누적 ε가 조금씩 달라 결과에 실제 ε·δ를 따로 적습니다.
  • ε는 모델 하나에 대한 값이며, 반복 실행과 하이퍼파라미터 탐색 전체의 공개는 합쳐 계산하지 않았습니다.

04

구체적으로 어떤 방법을 시험했나요?

바로 답하면이미 있는 이미지 특징으로 분류 부분만 학습하고(P1), 보호된 클래스 요약을 주고받아 분류기가 더 고르게 배우게 했습니다(P2와 수정판 두 가지).

이번 구현과 원래 설계는 P1·B4·B5가 다릅니다.

P1 · 마지막 분류 부분만 학습

  1. 이미지
  2. 특징 추출기 (ImageNet 사전학습)고정
  3. 분류기DP 학습
  4. 8개 클래스 확률

이번: 이번 제출: 특징 추출기는 모두 고정하고 분류기만 DP로 학습합니다.

  1. 이미지
  2. 특징 추출기 (대부분)고정
  3. 마지막 block 또는 LoRADP 학습
  4. 분류기DP 학습
  5. 8개 클래스 확률

원 설계: 원래 설계: 마지막 block 또는 LoRA를 분류기와 함께 DP로 미세조정합니다. block 버전은 4차에 제출했고(P1-block), LoRA 버전은 시작 전입니다.

P2 · 보호된 클래스 요약을 주고받아 분류기를 고르게 재학습

  1. 기록별 특징 클리핑
  2. 클래스별 합과 개수
  3. 합계에 노이즈
  4. 클래스 요약 공개
  5. 균형 가상 특징 생성이미지가 아닌 숫자 벡터
  6. 분류기 재학습
이후 수정 시도: P2-PCA와 P2-LA

P2-PCA

공개 보조 특징(DermaMNIST)으로 PCA 차원 축소를 맞춘 뒤 저차원에서 위의 6단계를 수행합니다. ISIC 시험 세트와 겹치는 DermaMNIST 이미지는 뺐고, 남은 이미지는 ISIC 학습 세트에 들어 있습니다.

관찰: 클래스마다 오르내림.

P2-LA

특징 합을 공개하지 않고 분류기도 다시 학습하지 않습니다. DP 클래스 개수로 예측 점수를 보정합니다(Logit Adjustment).

관찰: 제한적 개선.

요약과 다음 단계

  1. 우리는 프라이버시 보호 학습이 표본이 적은 피부 병변 클래스에 주는 영향을 연구합니다.
  2. 공개 데이터와 클라이언트 6개의 연합학습 모의 실험으로 실제 학습 방식과 개선 시도를 비교합니다.
  3. 실험은 진행되었고 일부 관찰과 수정 결과를 제출했으며, 안정적 개선은 더 검증해야 합니다.

다음 단계의 중점

  1. 기존 결과와 프라이버시 예산 검토 (DP 회계, 2단계 공개의 합성) ○ 시작 전
  2. 공정한 대조와 다중 시드 반복 검증, LoRA 버전 P1 추가 ○ 시작 전
  3. ChestX-ray14(K=10)와 ISIC 분포 변화 실험 진행 ○ 시작 전

부록: 초등학생을 위한 1분 애니메이션

일곱 장면으로 우리가 하는 일을 설명합니다. 그림은 설명용이며 실험 수치가 없습니다.

  1. 무엇을 하나요? 컴퓨터가 피부 점 8종류를 알아보도록 가르쳐요. 어떤 점은 사진이 많고(갈색 동그라미), 어떤 점은 적어요(보라색 마름모).
  2. 사진은 밖으로 안 나가요 사진은 상자 6개(서로 다른 출처 6곳을 흉내 냄)에 나뉘어 있고, 한 장도 꺼내지 않아요.
  3. 로봇이 나눠서 공부해요 선생님(서버)이 꼬마 로봇(모델)을 6개로 복사해 상자마다 하나씩 보내고, 로봇들이 동시에 사진을 보며 공부해요.
  4. 공부하며 안개 뿌리기 로봇은 한 걸음 배울 때마다 ‘안개’(노이즈)를 조금 뿌려요. 어떤 사진이 들어 있었는지 아무도 알 수 없어요. 이것이 차등 프라이버시예요.
  5. 공부 노트만 가져와요 로봇은 ‘공부 노트’(모델 파라미터)만 선생님에게 주고, 선생님은 노트 6개를 하나로 합쳐요. 사진은 계속 상자 안에 있어요. 이것이 연합학습이에요.
  6. 적은 것은 잘 잊어요 안개가 같아도 사진이 적은 점은 더 쉽게 잊혀요. 실험에서 본 현상이고, 그림은 설명용이에요.
  7. 방법을 찾고 있어요 드문 점도 기억하도록 여러 방법을 시험했어요. 아직 조금 나아진 정도이고, 결과는 친구들이 확인하고 있어요.
