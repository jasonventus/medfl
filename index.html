04

두 단계 제안 방법

  • P1: ImageNet 사전학습 EfficientNet-B0 또는 ResNet-18, 입력 224×224. 대부분을 고정하고 마지막 블록/LoRA 및 분류기만 DP-SGD로 학습합니다. BatchNorm 등 비호환 모듈을 GroupNorm 등으로 수정하고 Opacus로 검사합니다. 사전학습 가중치 전환의 영향도 비교 조건에 기록합니다.
  • P2: 각 보호 단위의 특성 벡터를 R로 클리핑하고 클래스별 합과 수에 노이즈를 넣어 서버에 보냅니다. 서버는 noisy sum/noisy count로 평균을 구하고 클래스별 동수의 가상 특성으로 분류기를 재학습합니다. 가상 특성의 분포·분산·표본수는 아직 결정해야 하며 추정 실데이터 통계도 회계에 포함합니다.

목표 최종 ε≤3.0, δ<1/n_i. 원문의 (ε₁,ε₂)=(2.7,0.3)과 ε₂∈{0.1,0.3,0.5,1.0}은 탐색안입니다. ε 숫자만 더하거나 두 번 변환해 보장하지 않습니다. 각 기관의 모든 라운드와 통계 릴리스를 동일한 RDP 차수에서 합성하고 최종 δ로 한 번 변환·검증합니다.

05

프라이버시 검토 조건

  • 이미지 수준 DP는 자동으로 환자 수준 DP가 되지 않습니다. 환자 식별자·중복·여러 병변을 감사하고 한 환자 한 레코드 또는 환자 단위 gradient/그룹 보장을 구현할 때만 환자 수준을 주장합니다. 불가능하면 이미지/레코드 수준으로 명확히 제한합니다.
  • 환자가 한 기관에만 속하고 조건부 각 기관 메커니즘이 전체 상호작용에 대해 DP를 만족할 때만 병렬 합성 논증을 사용할 수 있습니다. 사이트별 누적 회계와 전체 transcript 검토가 필요하며 매 라운드 accountant를 초기화하지 않습니다.
  • 합과 수는 공동 릴리스입니다. 고정 인코딩·단일 레이블·add/remove 인접성에서 한 블록의 합 민감도≤R, 수≤1이지만 공동 벡터/개별 노이즈의 비용을 함께 검토합니다. 다중 레이블에서 한 환자가 여러 클래스에 기여하므로 단일 클래스 가정을 그대로 쓰지 않습니다.
  • R의 중앙값, 가중치, 클래스 수, 집계 가중치, 그룹별 클리핑 임계값을 비공개 데이터에서 추정하면 추가 프라이버시 비용을 검토합니다. 공개 데이터나 사전 고정 규칙을 우선합니다.
  • noisy count≤0 또는 매우 작은 수에 대한 floor/억제와 빈 클래스 처리를 사전 정의합니다. DP 출력의 후처리만 사용하고 실제 수를 다시 조회하지 않습니다. 희귀 클래스 통계의 불안정성을 보고합니다.
  • 튜닝·조기중단·반복 seed·모델 선택·중간 체크포인트·평가 공개를 포함하는 릴리스 회계를 기록합니다. 튜닝 횟수를 적는 것만으로 DP가 복구되지는 않습니다. ε=8/∞ 실험은 목표 범위 밖의 연구 비교로 분리합니다.

기준 자료: 김은결의 중국어·영어 실험설계서 v1.0, 2026-11-02. 한국어는 이번 업데이트의 번역·편집본입니다. RQ와 방법은 제안이며 성능 개선·환자 수준 DP는 검증된 사실이 아닙니다. 원문에 추가한 검토 조건은 PRIVACY_REVIEW.md에 분리했습니다.

  • 클래스별 DP 비용=비DP 성능−DP 성능; 다수/희귀 클래스 비용 차이, 기관별 평균·최소 성능, 최종 ε/δ를 보고합니다. 테스트에 해당 클래스의 양성/음성이 없으면 지표를 임의로 0으로 두지 말고 N/A와 표본수를 보고합니다.
  • C∈{0.1,0.5,1.0}, batch 128–512, 30–50 라운드, 라운드당 local epoch 1은 원문의 탐색 범위입니다. seed≥3, mean±SD를 계획합니다. 공개 탐색 및 자원 검증 후 실행 설정을 고정합니다.
  • 수업의 중앙집중식 대비≥95% 유지율은 보조 목표로 보존합니다. 주 지표를 사전 정의하고 동일 모델·데이터·전처리에서 비율을 계산합니다. 전체 정확도 하나로 희귀 클래스 효과를 판단하지 않습니다.
  • 원 설계에서 MIA는 선택사항이나 수업 과제의 공격평가 지표는 유지합니다. 기본 MIA 점검을 계획하고 확장 공격/기관 수 실험만 선택적으로 수행합니다. DP 증명을 대체하지 않습니다.
  1. DermaMNIST로 데이터 단위·Flower/Opacus·회계를 점검.
  2. Fed-ISIC의 B2/B3로 RQ1을 먼저 확인. 효과가 없으면 가설이나 범위를 수정.
  3. B0–B5/P1/P2, 예산 곡선과 절제실험 수행.
  4. 환자 단위와 다중 레이블 민감도 검토 후 Chest 검증.
  5. 시간·자원이 허용되면 확장성·MIA 추가.

버전과 변경 기록

2026-11-02 · 연구 설계 v2 · 김은결 설계서 기반. 새 실험은 실행하지 않았으며 승인/인증을 주장하지 않습니다.

  • 일반 3노드 실험 → 희귀 클래스의 DP 비용이라는 구체적 RQ1–RQ3.
  • MedMNIST 중심 제안 → DermaMNIST 예비 점검 + Fed-ISIC 주 실험 + NIH 추가 검증.
  • 4개 거친 비교 → B0–B5, P1/P2, 6개 실험, seed≥3 계획.
  • 전체 성능 중심 → 희귀·최악 클래스, 기관별 성능과 예산 누적 검토.
  • 이력 링크만 제공 → 원본 사이트 v1와 업데이트 직전 사이트, 두 저장소 보존 분기 및 해시 목록.
