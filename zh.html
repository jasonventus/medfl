课题 05 · 公开皮肤病变图像 · 隐私保护训练

保护隐私时，样本少的皮肤病变类别会不会更容易被漏识别？

我们用公开皮肤病变图像，在六个客户端中开展联邦学习模拟，研究隐私保护对少数类别*识别的影响，并比较缓解这种影响的方法。

直接回答目前的观察是：会。加入隐私保护后，皮肤纤维瘤和血管病变比常见的色素痣下降得多；试过的缓解办法还没有稳定改善。结果待复核。

3 分钟看懂研究查看实验进展

成员协作仓库 ↗小学生版动画

* 少数类别：当前训练划分中样本占比较低的类别，本研究看皮肤纤维瘤（DF）和血管病变（VASC）；不等于临床罕见病。

技术细节：任务、指标与隐私单位
  • 任务：Fed-ISIC2019 的 8 类皮肤病变分类。
  • 指标：逐类别召回率；平衡准确率（8 个类别召回率的平均）；Macro-F1（8 个类别 F1 的平均）。
  • 隐私：图像/样本级差分隐私（DP-SGD 训练，RDP 记账），每个模型的目标上限 ε≤3。图像级保护不自动等于患者级保护。
  • 适用范围：公开数据上的联邦模拟，6 个来源分区。

03

公开数据为什么还能做联邦学习？

直接回答我们使用可获取、可复现的公开数据，模拟数据分散在不同参与方的条件，比较不同协作训练与隐私保护方法。

公开数据材料来源

图像来自公开数据集，可下载核对；没有使用医院病历。

联邦学习分区协作

图像留在各分区，本地训练后只把模型参数交给服务器合并，这叫联邦学习（FL）。

差分隐私限制单条记录的影响

训练时限制每张图的影响并加噪，看不出某张图在不在里面，这叫差分隐私（DP）；预算 ε 越小保护越强。

  1. 服务器把当前模型发给 6 个客户端 发出的是模型参数，不含任何图像。
  2. 各客户端在本地训练：DP-SGD 逐样本梯度裁剪 + 加噪 每一步训练先限制每张图像的梯度贡献，再加入高斯噪声。图像始终留在本地。
  3. 只上传受保护的模型更新 上传的是用 DP-SGD 训练后的模型参数，不是图像。P2 另外一次性上传加噪的类别统计。
  4. 服务器加权平均，得到下一轮模型 按各客户端样本量加权平均（FedAvg），再发回去，重复多轮。模型变了不等于更准，要用测试集评价。

为什么少数类别可能更吃亏？

概念示意强度（非真实 ε 或准确率数值）

同一层干扰下，数量少的菱形更难辨认。

滑块只改变图层遮挡，不运行 DP，也不对应真实 ε 或准确率。

技术细节：隐私设置
  • 联邦平均（FedAvg）：服务器按各客户端样本量加权平均模型参数。
  • DP-SGD：每一步先把每张图像的梯度裁剪到固定范数，再加高斯噪声；用 RDP 记账换算成 (ε, δ)，δ 固定。
  • 保护单位：ISIC 实验为图像/样本级；胸片扩展实验为患者级。
  • 预算：每个模型的目标上限 ε≤3；P2 的类别统计发布也计入预算。各方法的实际累计 ε 不完全相同，结果单列实际 ε、δ。
  • ε 只针对单个模型；多次重复与调参的整体发布没有合并计算。

04

我们具体尝试了什么方法？

直接回答先用已有图像特征只训练分类部分（P1），再交换受保护的类别摘要，让分类器更均衡地学习（P2 及两个修正版）。

本轮实现与原设计在 P1、B4、B5 上不同。

P1 · 只训练最后负责分类的部分

  1. 图像
  2. 特征提取器（ImageNet 预训练）冻结
  3. 分类头DP 训练
  4. 8 类概率

本轮：本轮提交：特征提取器全部冻结，只有分类头用 DP 训练。

  1. 图像
  2. 特征提取器（大部分）冻结
  3. 最后一个 block 或 LoRADP 训练
  4. 分类头DP 训练
  5. 8 类概率

原设计：原设计：最后一个 block 或 LoRA 与分类头一起用 DP 微调。block 版已在第 4 轮提交（P1-block），LoRA 版尚未开展。

P2 · 交换受保护的类别摘要，再均衡地重训分类头

  1. 逐记录特征裁剪
  2. 按类别求和与计数
  3. 对汇总量加噪
  4. 发布类别摘要
  5. 构造均衡虚拟特征数值向量，不是图像
  6. 重训分类头
后续修正尝试：P2-PCA 与 P2-LA

P2-PCA

先用公开辅助特征（DermaMNIST）拟合 PCA 降维，再在低维空间做上面 6 步。DermaMNIST 已剔除与 ISIC 测试集重叠的图片；留下的图片仍在 ISIC 训练集中。

观察：各类别有升有降。

P2-LA

不发布特征和，也不重训分类头；用 DP 类别计数校正预测分数（Logit Adjustment）。

观察：有限改善。
