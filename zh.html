04

两阶段拟议方案

  • P1：ImageNet 预训练 EfficientNet-B0 或 ResNet-18，输入224×224；冻结大部分参数，仅用 DP-SGD 训练最后模块/LoRA及分类器。将不兼容的 BatchNorm 改为 GroupNorm 等兼容模块，并由 Opacus 检查；记录转换预训练模块对公平比较的影响。
  • P2：将每个受保护单位的特征范数裁剪至 R，对各类别特征和、计数加入噪声后发至服务器，以 noisy sum/noisy count 计算均值，再用每类等量虚拟特征重训分类器。虚拟特征分布、方差及生成数量尚需定义；若使用私有估计也应计账。

目标最终 ε≤3.0，δ<1/n_i。原文默认(ε₁,ε₂)=(2.7,0.3)，ε₂∈{0.1,0.3,0.5,1.0}仅作为搜索方案。不能仅把 ε 标签相加或分别转换后即宣称达标；应按统一 RDP 阶数累计每院全部轮次与统计发布，最后在固定 δ 下统一转换并验证。

05

隐私审查条件

  • 图像级 DP 不自动等于患者级 DP。核查患者标识、重复图像及多个病变；只有实现每患者一条记录、患者级梯度或合理的组隐私保证后，才能声称患者级保护。否则明确限定为图像/记录级。
  • 仅当患者不跨院重复、各院条件机制覆盖完整交互并满足 DP 时，才可使用并行组合论证。审查完整可观察输出和各院累计会计，不能每轮清零 accountant。
  • 特征和与计数构成联合发布。固定编码、单标签、增删邻接下，某一块的和敏感度≤R、计数≤1，但需一起分析联合向量/噪声的成本。多标签患者可影响多个类别，不能直接套用单类别论证。
  • 私有数据上的特征范数中位数 R、类别权重/计数、聚合权重和自适应裁剪阈值可能产生额外隐私成本；优先使用公开数据或预先固定规则。
  • 预先定义 noisy count 非正或极小时的 floor/抑制、空类别处理。只后处理 DP 输出，不再读取真实计数；报告罕见类别统计不稳定性。
  • 对调参、早停、重复种子、模型选择、中间检查点及公开评价结果制定发布会计。仅注明调参次数不能恢复 DP 保证；ε=8/∞ 属于目标范围外研究参照。

依据：金銀潔2026-11-02中英文实验设计书v1.0。韩语为本次翻译与编辑整合。RQ和方法是提案，不能将性能改进或患者级DP写成既成事实。相对原文新增的技术审查条件单列于PRIVACY_REVIEW.md。
