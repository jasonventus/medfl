研究概览

在可比条件下比较单院、集中式、联邦和联邦+DP。ε≤3.0、相对集中式基准≥95%的性能保持率是待验证目标，并非已实现结果。训练前确定 δ、隐私保护单位和主指标，评估各院性能与成员推断攻击（MIA）。

建议起步：MedMNIST v2 中一个待选子集 + PyTorch + Flower + Opacus。实际使用前核查数据获取方式和库版本。公开数据集中式训练仅作为实验基准。

05

版本留存

每个 commit 保存当时全部已跟踪文件的逻辑快照。通过 Commits → 某次记录 → Browse files 查看旧版本，再用 Code → Download ZIP 导出。撤销通过新建 revert 提交。禁止 force push、重写共享历史、squash、rebase 或 amend 已共享提交。

未提交或未推送的修改、忽略文件、外部数据和模型权重不会自动留存，LFS 实际对象也需单独备份。各里程碑运行 bash backup.sh 生成 Git bundle 和 HEAD ZIP，再复制到独立团队存储。所有者仍能删除或改写历史，Git 并非不可篡改存储。
